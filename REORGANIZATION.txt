🚀 HOW TO RUN EACH VERSION
═══════════════════════════════════════════════════════════════

PYTHON VERSION (from root directory):
  flask run
  # or
  python app.py
  
  → Access at http://127.0.0.1:5000

RUST VERSION (from root directory):
  cd rust
  ./run.sh
  # or
  cargo run --release
  
  → Access at http://127.0.0.1:5000

RUST VERSION (from rust/ directory):
  ./run.sh
  # or
  cargo run --release
  
  → Access at http://127.0.0.1:5000
